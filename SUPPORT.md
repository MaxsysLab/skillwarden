# Getting Support

- **Questions and how-to:** open an issue and choose the Question template. The
  [README](README.md) covers the commands, the exit codes and what makes a scan
  incomplete; your answer may already be there.
- **A missed detection:** something hostile scanned as clean. Open an issue with the
  Missed Detection template and include the smallest text that shows it.
- **A false alarm:** something harmless was flagged. Open an issue with the False Alarm
  template and include the line that was flagged and the rule that fired.
- **Bugs:** open an issue with the Bug Report template.
- **Feature ideas:** open an issue with the Feature Request template. File the issue
  *before* a large pull request (see [CONTRIBUTING.md](CONTRIBUTING.md)).
- **Security vulnerabilities:** do **not** open a public issue. Follow
  [SECURITY.md](SECURITY.md).

We aim to give a first response within 3 business days. That is a target, not a
guarantee. Maintainers and contributors are volunteers; please be patient and kind.

SkillWarden is open-source software offered as it is, without warranty (see
[LICENSE](LICENSE)). There is no paid support through this project.
